# Практическая работа 12

**Управление сервоприводом и вывод данных на LCD1602**

МДК 02.02 Программирование микроконтроллеров
4 курс колледжа • 4 академических часа • 25 вариантов

Разработайте последовательно три версии одной программы управления сервоприводом. Затем найдите и исправьте ошибки в двух отдельных скетчах. Номер варианта соответствует номеру по журналу.

## Цель и результаты работы

Освоить управление положением сервопривода средствами библиотеки Servo, отображение заданного угла на LCD1602 и проверку программы по библиотечным примерам Arduino IDE.

После работы студент умеет объединять изученные примеры, изменять диапазон и темп движения, считывать потенциометр и кнопку, выводить данные на LCD и обосновывать исправления в коде.

## Обязательное требование к разработке кода

Весь код трех задач и все исправления в двух заданиях на отладку должны быть разработаны только на основе примеров программ, доступных через меню «Файл → Примеры» Arduino IDE для установленных библиотек и модулей. Самостоятельно найдите, изучите и объедините необходимые фрагменты. Готовые решения из интернета, генерация кода и дополнительные библиотеки не допускаются.

Разрешены изменение констант, имен переменных, границ циклов, выводимого текста и подключений, а также объединение и перестановка конструкций из разрешенных примеров. Каждую примененную функцию и управляющую конструкцию свяжите с конкретным примером в отчете. Готовые библиотечные программы в задании не приводятся; неисправные листинги ниже являются материалом для отладки.

## Оборудование и подготовка

Arduino Uno R3 на ATmega328P, позиционный сервопривод SG90, LCD1602 с I²C-адаптером, потенциометр 10 кОм, одна кнопка, резистор 10 кОм, макетная плата, провода, USB-кабель и ПК с Arduino IDE. Для серво используйте согласованный с преподавателем стабилизированный источник 5 В с достаточным током, ориентировочно от 1 А для одного SG90 без нагрузки.

Применяется позиционный серводвигатель, а не привод непрерывного вращения. Сборку выполняйте при отключенном питании. Снимите механическую нагрузку и проверьте допустимый ход конкретного привода; при упоре или сильном гудении отключите питание и сообщите преподавателю.

### Подключения

Таблица 1 — Подключения для всех вариантов

| Элемент | Подключение |
| --- | --- |
| LCD1602 I²C | VCC → 5V Arduino; GND → GND; SDA → A4; SCL → A5 |
| Сервопривод | Сигнальный провод → D9; питание → внешний источник 5 В; земля → общий GND |
| Потенциометр | Крайние выводы → 5V и GND Arduino; средний вывод → A0 |

Кнопка отпущена — LOW, нажата — HIGH. На четырехконтактной кнопке используйте контакты разных электрических групп. Резистор 10 кОм задает устойчивый уровень входа; резистор 220 Ом для этой подтяжки не применяется.

### Подготовка в Arduino IDE

1. На ПК выберите плату Arduino Uno и соответствующий порт. При отсутствии поддержки установите пакет Arduino AVR Boards через менеджер плат. Проверьте загрузку штатного примера Blink.

2. Убедитесь, что доступны Servo и LiquidCrystal_I2C. Для LCD используйте согласованную библиотеку с API init(), backlight(), setCursor(), print() и примером HelloWorld, совместимую с johnrickman/LiquidCrystal_I2C. Если библиотеки отсутствуют, установите их через менеджер библиотек или «Подключить библиотеку → Добавить ZIP-библиотеку». Преподаватель заранее предоставляет архивы при отсутствии интернета. Не смешивайте одноименные библиотеки с разным API.

3. Откройте четыре разрешенных примера. Для LCD укажите фактический адрес адаптера и геометрию 16 × 2. Адрес 0x27 ниже — рабочее допущение; преподаватель подтверждает адрес стенда до выполнения. В исходном HelloWorld могут быть размеры 20 × 4 — их требуется адаптировать.

4. Проверьте устройства по отдельности, затем соберите общую схему. При пустом LCD проверьте питание, адрес, проводку и подстроечный резистор контраста. Исправность компиляции сама по себе не подтверждает исправность устройства.

## Необходимые сведения

Библиотека Servo формирует управляющие импульсы с использованием таймера. Значение write задает требуемое положение. Обычный analogWrite не заменяет управление позиционным сервоприводом. Регистры таймера и ручную генерацию импульсов в этой работе программировать не требуется.

Переменная угла и значение на LCD отражают команду программе, а не результат измерения фактического положения вала. Пауза определяет темп выдачи команд.

LCD имеет 16 столбцов с номерами 0–15 и две строки с номерами 0–1. Используйте латинские надписи. При обновлении числа перезаписывайте всю строку либо поле с запасом пробелов, чтобы переход от трех цифр к двум не оставлял старый символ. Используйте setCursor и print из HelloWorld.

## Общие условия трех задач

Обозначения варианта: L — нижний угол, H — верхний угол, T0 — задержка базового движения, Tf и Ts — минимальная и максимальная задержки регулируемого движения. Все углы указаны в градусах, задержки — в миллисекундах. Шаг движения во всех вариантах равен 1°. Метка Vxx содержит номер варианта.

Сохраните три самостоятельных скетча: PR12_Vxx_1, PR12_Vxx_2 и PR12_Vxx_3. Вторую версию создайте копированием первой, третью — копированием второй. В отчете покажите, какие блоки сохранены и что добавлено.

### Задача 1 Базовый уровень

На основе Sweep и HelloWorld создайте непрерывное перемещение L → H → L с шагом 1° и паузой T0 после каждой команды. На первой строке LCD отображайте «Vxx AUTO», на второй — «Angle: N deg», где N — последний заданный угол. Угол и надпись обновляйте внутри обоих циклов. Начальное задание — L.

Проверка: продемонстрируйте не менее двух полных циклов, оба граничных положения и соответствие числа на LCD последней команде.

### Задача 2 Средний уровень

В копии задачи 1 сохраните оба цикла, границы и вывод угла. Добавьте потенциометр: считывайте A0 и преобразуйте диапазон 0–1023 в Tf–Ts средствами Knob. Полученную задержку используйте вместо T0. Считывайте потенциометр перед каждым шагом, чтобы темп можно было менять во время движения. Первая строка — «Vxx SPEED».

Проверка: при трех положениях потенциометра продемонстрируйте различный темп, сохранение L и H и обновление LCD в обоих направлениях. В отчете укажите показания АЦП и рассчитанную задержку. Для середины диапазона допустимо целочисленное округление map.

### Задача 3 Повышенный уровень

В копии задачи 2 сохраните регулировку темпа, оба цикла и индикацию. Добавьте кнопку по примеру Button. В начале каждого прохода loop проверяйте D2: HIGH запускает один полный цикл L → H → L, LOW оставляет вал в L и выводит «Vxx READY». Во время цикла выводите «Vxx RUN». Удержание кнопки запускает последовательные полные циклы; после отпускания текущий цикл завершается, затем начинается ожидание.

Это управление по уровню кнопки: короткое нажатие во время уже выполняемого цикла не запоминается. Прерывание цикла, переключение режима по фронту и устранение дребезга в условия не входят. В ожидании используйте короткую паузу 20 мс; на второй строке сохраняйте заданный угол.

Проверка: ожидание после запуска; один цикл при отпускании кнопки во время движения; повторение при удержании; возврат в ожидание после отпускания; регулировка темпа потенциометром во время цикла.

### Задание 4 Поиск ошибок подключения объектов и LCD

Требуемое поведение: вал попеременно получает команды L и H с паузой T0; LCD показывает «Vxx DEBUG4» и соответствующий заданный угол. Найдите все причины, мешающие компиляции или выполнению этого поведения. Исправьте минимально необходимое число строк, сохранив структуру программы.

```cpp
#include <Servo.h>
#include <LiquidCrystal_I2C.h>
Servo drive;
LiquidCrystal_I2C lcd(0x27, 16, 2);
int L = 20, H = 140, T0 = 20;
void setup() {
  drive.attach(8);
  lcd.init;
  lcd.backlight();
}
void loop() {
  drive.write(L);
  lcd.setCursor(0, 0);
  lcd.print("Vxx DEBUG4");
  lcd.setCursor(0, 2);
  lcd.print("Angle: "); lcd.print(H); lcd.print(" deg   ");
  delay(T0);
  drive.write(H);
  lcd.setCursor(0, 2);
  lcd.print("Angle: "); lcd.print(L); lcd.print(" deg   ");
  delay(T0);
}
```

Доказательства: сообщение компилятора до исправления, таблица найденных причин с указанием примеров-источников, успешная компиляция после исправления и наблюдение обеих команд. Задержка T0 здесь разделяет команды, но не гарантирует достижение валом крайних положений за это время.

### Форма фиксации исправлений

Для каждого дефекта запишите: строку или фрагмент → симптом → причина → внесенное исправление → путь к примеру Arduino IDE → результат повторной проверки. Одинаковую ошибку в нескольких строках укажите с перечислением всех мест. Не ограничивайтесь сообщением «теперь работает».

## Задание 5 Поиск логических ошибок движения и индикации

Требуемое поведение: непрерывное движение L → H → L с шагом 1° и паузой T0, первая строка LCD «Vxx DEBUG5», вторая — последняя команда угла. Программа может компилироваться, но это не подтверждает соответствие условию. Исправьте ошибки в циклах, передаче команды и выводе данных, опираясь на Sweep и HelloWorld.

```cpp
#include <Servo.h>
#include <LiquidCrystal_I2C.h>
Servo drive;
LiquidCrystal_I2C lcd(0x27, 16, 2);
int L = 20, H = 140, T0 = 20;
int pos = 0;
void setup() {
  drive.attach(9);
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Vxx DEBUG5");
}
void loop() {
  for (pos = L; pos <= H; pos += 1) {
    drive.write(H);
    lcd.setCursor(0, 1);
    lcd.print("Angle: "); lcd.print(pos); lcd.print(" deg");
    delay(T0);
  }
  for (pos = H; pos <= L; pos -= 1) {
    drive.write(pos);
    lcd.setCursor(0, 0);
    lcd.print("Angle: "); lcd.print(pos); lcd.print(" deg");
    delay(T0);
  }
}
```

Проверьте движение в обоих направлениях, сохранность заголовка, соответствие числа команде и переход от угла с тремя цифрами к углу с двумя. Все варианты специально содержат такой переход. Исправьте и дефект обновления поля, который становится заметен только после восстановления обратного движения.

| 3 — запуск кнопкой | Сохранить движение и регулировку из задачи 2; кнопка D2 разрешает полный цикл по общим правилам; заголовки «Vxx READY» и «Vxx RUN». |
| 4 — исправление первого листинга | В исходном неисправном листинге задать L, H и T0 из своей строки таблицы и метку «Vxx DEBUG4»; исправить ошибки, проверить обе команды и LCD. |
| 5 — исправление второго листинга | В исходном неисправном листинге задать те же L, H и T0 и метку «Vxx DEBUG5»; исправить ошибки, проверить оба направления и обновление числа при переходе 100° → 99°. |

В обозначении Vxx замените xx двузначным номером своего варианта. На второй строке LCD во всех задачах отображается последний заданный угол. Подстановка параметров в неисправные листинги — подготовка исходных данных, а не исправление ошибки.
