## Оснащение (оборудование и программное обеспечение)

- Arduino Uno (допускается Arduino Nano), компьютер с Arduino IDE и USB-кабель.
- Макетная плата, соединительные провода, кнопка, один светодиод и резистор 220–330 Ом.
- Потенциометр для заданий, в которых используется аналоговый вход A0.
- Монитор последовательного порта со скоростью 9600 бод. Симулятор допускается по согласованию с преподавателем.

## Описание устройства и подключений

Во всех задачах одного варианта используются одинаковые обозначения выводов. Соберите цепи, необходимые для конкретной задачи:

| Элемент | Подключение | Назначение |
| --- | --- | --- |
| Кнопка | Между цифровым входом D2 и GND | В программе настройте `INPUT_PULLUP`: отпущена — `HIGH`, нажата — `LOW`. |
| Светодиод | D9 → резистор 220–330 Ом → анод светодиода; катод → GND | Индикация режима или достижения порога. |
| Потенциометр | Крайние выводы → 5V и GND; средний вывод → A0 | Изменение измеряемого аналогового значения. |
| Последовательный порт | Arduino → USB → компьютер | Ввод команд и наблюдение результатов в Serial Monitor. |

Для Arduino Nano используйте выводы с теми же обозначениями. В задачах без кнопки или потенциометра соответствующие цепи можно не собирать. Если схема соединений в вашем макете отличается от таблицы, приложите её к отчёту и согласуйте с преподавателем.

## Описание задания и порядок выполнения

1. Выполните **три самостоятельных скетча** по задачам 1–3 своего варианта: разработайте программу по указанному алгоритму.
2. В задачах 4–5 найдите ошибки в приведённых скетчах, объясните причины и исправьте программы так, чтобы устройство работало согласно требованию. В одном скетче может быть несколько ошибок.
3. Для каждой задачи создайте отдельную папку с одноимённым файлом `.ino`. Скомпилируйте скетч, загрузите его на плату и проверьте стартовое состояние, переходы режимов, граничные условия и сброс.
4. Покажите преподавателю работу всех пяти программ. В таблице испытаний для каждой задачи укажите действие, ожидаемый и фактический результат.

**Общие условия:** стартовое состояние — выход выключен, счётчик равен нулю, если условие задачи не задаёт иное. Короткое нажатие определяйте по фронту с подавлением дребезга 30 мс; удержание считается одним нажатием. Команды вводятся отдельной строкой с переводом строки; завершающий `\r` и пробелы удаляйте. Для совмещения счёта времени и ввода применяйте `millis()` и тип `unsigned long`, сравнивайте интервалы вычитанием. Периодический вывод не должен блокировать кнопку и команды.

## Содержание отчёта

1. Титульный лист.
2. Задание по своему варианту (номер и условия пяти задач).
3. Схемы подключения для задач, где они требуются; если одна схема подходит нескольким задачам, достаточно привести её один раз и указать номера этих задач.
4. Листинги пяти программ с комментариями; для задач 4–5 также пояснение найденных ошибок и внесённых исправлений.

6. Отдельный вывод по каждой из пяти задач.

## Оценивание

Работа оценивается по пятибалльной системе. Преподаватель учитывает правильность алгоритмов и работы макета, умение находить и объяснять ошибки, качество исправлений, результаты проверки и полноту отчёта.

- **«5» (отлично)** — выполнены все пять задач; программы работают по заданным алгоритмам, ошибки найдены и объяснены, отчёт полный.
- **«4» (хорошо)** — выполнены все пять задач; есть отдельные недочёты в программах, проверке или отчёте, которые не мешают продемонстрировать основные режимы работы.
- **«3» (удовлетворительно)** — выполнены не менее трёх задач, включая хотя бы одну задачу на исправление ошибок; основные результаты показаны, но имеются существенные недочёты.
- **«2» (неудовлетворительно)** — выполнено менее трёх задач либо не удалось продемонстрировать работу программ по заданным алгоритмам.

## Вариант 01 — Сигнализация двери

### Задача 1. Разработка режима работы

Для устройства «сигнализация двери» напишите скетч: короткое нажатие D2 переключает `WAIT → RUN → PAUSE → WAIT`. В `RUN` D9 горит, в остальных режимах выключен. При переходе выводите название режима в монитор последовательного порта. Старт — `WAIT`. Удержание кнопки не создаёт дополнительных переходов. Покажите два полных цикла.

### Задача 2. Разработка секундного цикла

Команды `start`, `stop`, `reset`, `status`: счёт секунд от 0 до **7**, пауза с сохранением значения, сброс в 0 с остановкой, запрос состояния. На верхней границе счёт автоматически останавливается и D9 загорается; после `reset` он гаснет. `start` после паузы продолжает счёт, а после достижения границы требует предварительного `reset`. Кнопка D2 запускает из начального состояния и ставит на паузу из работающего. При каждом изменении выводите значение счётчика в монитор последовательного порта. Покажите паузу, продолжение и границу.

### Задача 3. Разработка измерителя

Читать A0; при **A0 ≥ 362** включать D9, иначе выключать. Каждые **250 мс** выводить в монитор последовательного порта строку `A0=<число>;LED=ON/OFF`. По команде `s` немедленно выводите текущие данные в монитор последовательного порта без сдвига периодического расписания; `m` выводит в монитор последовательного порта минимум и максимум измерений с момента запуска; `r` начинает накопление заново с текущего значения. Проверьте ниже, на и выше порога.

### Задача 4. Найдите и исправьте ошибки

**Требование:** Короткое нажатие D2 переключает D9 один раз; удержание не повторяет переключение. Объясните неисправности и подтвердите исправление испытаниями.

```cpp
const byte BTN = 2, LED = 9;
bool on = false;
void setup() { pinMode(BTN, INPUT_PULLUP); pinMode(LED, OUTPUT); }
void loop() {
  if (digitalRead(BTN) == HIGH) {
    on = !on;
    digitalWrite(LED, on);
  }
}
```

### Задача 5. Найдите и исправьте ошибки

**Требование:** D9 мигает с полуинтервалом 250 мс; `0` немедленно выключает, `1` вновь запускает с выключенного состояния. Объясните неисправности и подтвердите исправление испытаниями.

```cpp
const byte LED = 9;
bool enabled = true;
unsigned long last = 0;
void setup() { Serial.begin(9600); pinMode(LED, OUTPUT); }
void loop() {
  if (Serial.available()) {
    char c = Serial.read();
    if (c == '0') enabled = false;
    if (c == '1') enabled = true;
  }
  if (millis() - last >= 250) {
    last = millis();
    digitalWrite(LED, !digitalRead(LED));
  }
}
```
