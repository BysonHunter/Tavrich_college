# Светофор

[← К общему содержанию](../README.md)

**Плата:** Arduino Uno/Nano (ATmega328P)  
**Среда:** Arduino IDE 2.x  
**Serial:** 9600 бод

### Общие замечания
- Для встроенного светодиода используйте `LED_BUILTIN`, а не жёстко заданный D13.
- Для неблокирующих задач применяйте `millis()`.
- Serial Monitor может добавлять `\r` и `\n`; это надо учитывать при разборе команд.
- Объект `String` допустим в учебных задачах, но на AVR следует помнить об ограниченном объёме SRAM.

## Цель
Реализовать последовательность временных состояний.

## Задание
Фазы:
1. `КРАСНЫЙ` — 3 с;
2. `ЖЕЛТЫЙ` — 1 с;
3. `ЗЕЛЕНЫЙ` — 3 с.

Каждую секунду выводите фазу и оставшееся время.

## Исправление исходного задания
В исходнике одновременно требуется использовать только встроенный светодиод и отображать разные цвета. Один монохромный LED цвет менять не может.

Допустимы:
- **программная имитация**: цвет показывается в Serial, LED лишь обозначает активность;
- **полноценный вариант**: три внешних LED через резисторы 220–330 Ом.

Для качественной реализации используйте конечный автомат и `millis()`.
