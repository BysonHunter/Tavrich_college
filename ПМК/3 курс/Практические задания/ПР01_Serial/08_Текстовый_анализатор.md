# Текстовый анализатор

[← К общему содержанию](../README.md)

**Плата:** Arduino Uno/Nano (ATmega328P)  
**Среда:** Arduino IDE 2.x  
**Serial:** 9600 бод

### Общие замечания
- Для встроенного светодиода используйте `LED_BUILTIN`, а не жёстко заданный D13.
- Для неблокирующих задач применяйте `millis()`.
- Serial Monitor может добавлять `\r` и `\n`; это надо учитывать при разборе команд.
- Объект `String` допустим в учебных задачах, но на AVR следует помнить об ограниченном объёме SRAM.

## Цель
Принимать целую строку и анализировать её.

## Задание
1. Читать строку до `\n`.
2. Выполнить `trim()`.
3. Подсчитать длину, буквы и цифры.
4. Вывести строку в верхнем регистре.
5. `led on` / `led off` управляют LED.

## Уточнения
- `String::toUpperCase()` изменяет строку на месте.
- `readStringUntil()` может ждать до тайм-аута; задайте разумный `Serial.setTimeout(...)`.
