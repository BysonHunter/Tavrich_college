# Частотный регулятор

[← К общему содержанию](../README.md)

**Плата:** Arduino Uno/Nano (ATmega328P)  
**Среда:** Arduino IDE 2.x  
**Serial:** 9600 бод

### Общие замечания
- Для встроенного светодиода используйте `LED_BUILTIN`, а не жёстко заданный D13.
- Для неблокирующих задач применяйте `millis()`.
- Serial Monitor может добавлять `\r` и `\n`; это надо учитывать при разборе команд.
- Объект `String` допустим в учебных задачах, но на AVR следует помнить об ограниченном объёме SRAM.

## Цель
Менять частоту мигания LED по числовой команде.

## Задание
- начальная частота — 1 Гц;
- ввод 1…10 задаёт новую частоту;
- `s` выводит текущую частоту и период;
- мигание продолжается во время ожидания команд.

## Формулы
```text
period_ms = 1000 / f
half_period_ms = period_ms / 2
```

## Уточнение
Основную логику выполняйте на `millis()`. При `delay()` команда пользователя может обрабатываться с большой задержкой.
