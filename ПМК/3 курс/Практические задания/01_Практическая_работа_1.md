## 1. Краткие Теоретические И Учебно-Методические

## Материалы По Теме Работы

1. Платформа Arduino
Arduino — это открытая платформа для прототипирования на основе

**микроконтроллеров. Состоит из:**

- Аппаратной части — плата с микроконтроллером (чаще ATmega328P)
- Программной части — среда разработки Arduino IDE
**Основные характеристики Arduino Uno:**

- Микроконтроллер: ATmega328P
- Рабочее напряжение: 5 В
- Цифровые пины: 14 (из них 6 ШИМ)
- Аналоговые входы: 6
- Память: 32 КБ Flash, 2 КБ SRAM, 1 КБ EEPROM
- Тактовая частота: 16 МГц
2. Структура программы Arduino
**Каждая программа (скетч) состоит из двух обязательных функций:**

`void setup() {`

// Выполняется один раз при старте // Инициализация пинов, настройка периферии }

`void loop() {`

// Выполняется циклически после setup() // Основная логика программы }

3. Цифровые входы/выходы
**Настройка пинов:**

`pinMode(pin, MODE); // MODE: INPUT, OUTPUT, INPUT_PULLUP`

**Чтение/запись:**

`digitalRead(pin); // Чтение: HIGH/LOW`

`digitalWrite(pin, value); // Запись: HIGH/LOW`

Встроенный светодиод: подключен к пину 13.

4. Последовательный порт (UART)
**Инициализация:**

`Serial.begin(speed); // speed: 9600, 115200 и т.д.`

**Методы передачи данных:**

`Serial.print(data); // Вывод без перевода строки`

`Serial.println(data); // Вывод с переводом строки`

`Serial.write(data); // Вывод бинарных данных`

**Методы приема данных:**

`Serial.available(); // Количество байт в буфере`

`Serial.read();      // Чтение одного байта`

`Serial.readString(); // Чтение строки`

`Serial.parseInt(); // Чтение целого числа`

5. Работа со временем
**Блокирующие задержки:**

`delay(ms);       // Задержка в миллисекундах`

delayMicroseconds(us); // Задержка в микросекундах

**Неблокирующий timing (рекомендуется):**

`unsigned long currentMillis = millis(); // Время с начала работы`

`if (currentMillis - previousMillis >= interval) {`

// Выполнить действие

`previousMillis = currentMillis;`

}

6. Типы данных и переменные
**Основные типы данных:**

boolean // Логический (true/false)

`byte // 0-255`

`int // Целое (-32768 до 32767)`

unsigned int // 0-65535 long // Большое целое

`float // Число с плавающей точкой`

`char // Символ`

`String // Строка (объект)`

**Области видимости:**

локальная // Внутри функции глобальная // Вне всех функций статическая // Сохраняет значение между вызовами

7. Управляющие конструкции
**Условные операторы:**

`if (condition) { ... }`

`else if (condition) { ... }`

`else { ... }`

`switch (variable) {`

`case value1: ... break;`

`case value2: ... break;`

default: ... break; }

**Циклы:**

`for (int i = 0; i < count; i++) { ... }`

`while (condition) { ... }`

`do { ... } while (condition);`

8. Функции
**Объявление функций:**

returnType functionName(parameters) { // Тело функции

`return value;`

}

**Пример:**

`int sum(int a, int b) {`

`return a + b;`

}

9. Массивы и строки
**Массивы:**

`int numbers[5] = {1, 2, 3, 4, 5};`

`char text[] = "Hello";`

**Работа со строками:**

`String str = "Arduino";`

str.length(); // Длина строки str.toUpperCase(); // В верхний регистр str.indexOf(«du»); // Поиск подстроки

10. Основные алгоритмы обработки ввода
**Обработка одиночных символов:**

`if (Serial.available() > 0) {`

`char command = Serial.read();`

// Обработка команды }

**Обработка чисел:**

`int number = Serial.parseInt();`

**Обработка строк:**

`String input = Serial.readStringUntil('\n');`

input.trim(); // Удаление пробелов

11. Принципы отладки
**Методы отладки:**

1. Serial Monitor — вывод состояния переменных
2. Светодиодная индикация — визуализация состояний
3. Контрольные точки — вывод сообщений в ключевых точках
**Пример отладочного вывода:**

`Serial.print("Переменная x = ");`

`Serial.println(x);`

`Serial.print("Время: ");`

`Serial.println(millis());`

12. Рекомендации по программированию
**Хорошие практики:**

Используйте понятные имена переменных, комментируйте сложные участки кода, избегайте блокирующих задержек в основном цикле, проверяйте границы значений при вводе, используйте константы вместо «магических чисел».

**Пример:**

`const int LED_PIN = 13;     // Вместо цифры 13`

`const long BLINK_INTERVAL = 1000; // Интервал мигания`

`pinMode(LED_PIN, OUTPUT);`

`Serial.begin(9600);`
