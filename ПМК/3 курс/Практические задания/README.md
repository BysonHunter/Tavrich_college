# Практические работы по программированию микроконтроллеров — 3 курс

Специальность: **09.02.01 «Компьютерные системы и комплексы»**  
Дисциплина/МДК: **Программирование микроконтроллеров**

Комплект подготовлен по шести исходным методическим PDF-файлам.  
**Каждое задание вынесено в отдельный Markdown-файл** — всего 40 заданий.

## Что исправлено и уточнено

При переносе сохранены темы и учебные цели исходных работ, но технические противоречия исправлены. В частности:

- 40 мА на выводе ATmega328P указано как absolute maximum, а не нормальный рабочий ток;
- для кнопок в большинстве схем принят `INPUT_PULLUP`;
- исправлены логические конфликты задач с одним LED/несколькими цветами;
- в тесте реакции исправлено несоответствие «3 LED — 2 кнопки»;
- в секвенсор добавлен явный способ запуска воспроизведения;
- «приоритетные прерывания» AVR уточнены как программный приоритет событий;
- серво описано через Servo-импульсы, а не как обычный PWM `analogWrite()`;
- длинные строки адаптированы к реальным 16 символам LCD1602;
- устранено противоречие одной кнопки Manual/Auto/hold;
- для 28BYJ-48 уточнены шаги на оборот, реальная скорость и ограничения ULN2003;
- «медианная фильтрация» HC-SR04 исправлена на фактически описанное усечённое среднее;
- исправлен слишком короткий UART-тайм-аут при пяти измерениях;
- калибровка HC-SR04 «без препятствий» заменена калибровкой по известной дистанции;
- для аппаратного UART Uno добавлено предупреждение о конфликте с USB-UART;
- исправлены конфликты пинов 7-сегментного индикатора с датчиками/кнопками;
- добавлено безопасное управление общими разрядами 7-seg через транзисторные ключи;
- исправлен алгоритм секундомера с паузой.

## Рисунки и схемы

В исходных PDF-файлах не обнаружено встроенных электрических схем или отдельных иллюстраций — документы состоят в основном из текста. Поэтому исходных рисунков для переноса не было. В Markdown добавлены таблицы подключения и уточнённые распиновки там, где это необходимо.

## Общие требования к отчёту

Для каждого отдельного задания в файле приведён минимальный состав отчёта. Для печатного варианта можно сохранить параметры исходных методичек:

- формат A4;
- левое поле — 3 см;
- правое — 1,5 см;
- верхнее и нижнее — 2 см;
- Times New Roman, 14 пт;
- межстрочный интервал 1,5;
- отступ первой строки 1,25 см;
- рисунки и подписи — по центру.

## Общие рекомендации по выполнению

1. Проверить схему до подключения питания.
2. Для исполнительных устройств с заметным током использовать подходящее внешнее питание.
3. Всегда объединять земли устройств, если они обмениваются логическими сигналами.
4. Использовать резисторы ограничения тока для LED.
5. Интерактивные системы строить на `millis()` и конечных автоматах вместо длинных `delay()`.
6. Перед сдачей проверить работу после reset и повторного включения.
