# BMP180 давление и температура на LCD

[← К общему содержанию](../README.md)

**Оборудование:** Arduino Uno, LCD1602 I²C, DHT22, BMP180, HC-SR04.  
**Типовые библиотеки из исходника:** `DHT`, `Wire`, `LiquidCrystal_I2C`, `SFE_BMP180`.

### Общие замечания
- DHT22 следует опрашивать с интервалом порядка 2 с.
- BMP180 и LCD могут находиться на одной I²C-шине, если адреса различаются.
- `pulseIn()` для HC-SR04 обязательно используйте с тайм-аутом.
- Все строки LCD должны помещаться в 16 символов.

## Цель
Измерять давление BMP180 и показывать hPa/mmHg на двух страницах.

## Задание
1. Каждые 5 с выполнять полный цикл BMP180.
2. Получать температуру и давление.
3. Пересчитывать:
```text
mmHg = hPa * 0.7500637554
```
4. Страницы переключать каждые 3 с через `millis()`.

### Страница 1
```text
T:24.3C
P:1013.2hPa
```

### Страница 2
```text
T:24.3C
P:759.9mmHg
```

## Обработка ошибок
Показывать `BMP180 ERROR` и конкретный этап: `INIT FAIL`, `TEMP FAIL`, `PRESS FAIL`.

## Уточнение
Измерение температуры у BMP180 используется для компенсации давления, поэтому типовая последовательность сначала получает температуру, затем давление.
