# HC-SR04 с фильтрацией и режимом DEBUG

[← К общему содержанию](../README.md)

**Оборудование:** Arduino Uno, LCD1602 I²C, DHT22, BMP180, HC-SR04.  
**Типовые библиотеки из исходника:** `DHT`, `Wire`, `LiquidCrystal_I2C`, `SFE_BMP180`.

### Общие замечания
- DHT22 следует опрашивать с интервалом порядка 2 с.
- BMP180 и LCD могут находиться на одной I²C-шине, если адреса различаются.
- `pulseIn()` для HC-SR04 обязательно используйте с тайм-аутом.
- Все строки LCD должны помещаться в 16 символов.

## Цель
Стабилизировать измерение расстояния и показывать сырые данные по запросу.

## Подключение
Trig → D12; Echo → D11; DEBUG → D3↔GND (`INPUT_PULLUP`).

## Исправление термина
Исходник называет алгоритм «медианной фильтрацией», но описывает: 5 значений → удалить min/max → усреднить оставшиеся 3. Это **усечённое среднее**, а не медиана.

## Алгоритм
1. Сделать 5 измерений с `pulseIn(..., 30000)`.
2. Обработать тайм-ауты.
3. Удалить min и max.
4. Среднее оставшихся 3 вернуть как расстояние.

## DEBUG — исправление отображения
Пять значений до 400 см не помещаются в одну строку LCD1602. Показывайте в две строки/страницы, например:
```text
R:012 013 011
014 012
```
