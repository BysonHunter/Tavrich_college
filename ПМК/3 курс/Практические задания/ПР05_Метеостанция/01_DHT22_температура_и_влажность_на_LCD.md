# DHT22 температура и влажность на LCD

[← К общему содержанию](../README.md)

**Оборудование:** Arduino Uno, LCD1602 I²C, DHT22, BMP180, HC-SR04.  
**Типовые библиотеки из исходника:** `DHT`, `Wire`, `LiquidCrystal_I2C`, `SFE_BMP180`.

### Общие замечания
- DHT22 следует опрашивать с интервалом порядка 2 с.
- BMP180 и LCD могут находиться на одной I²C-шине, если адреса различаются.
- `pulseIn()` для HC-SR04 обязательно используйте с тайм-аутом.
- Все строки LCD должны помещаться в 16 символов.

## Цель
Считывать DHT22 и показывать температуру/влажность на LCD.

## Подключение
- DATA DHT22 → D2;
- LCD SDA → A4;
- LCD SCL → A5.

Для отдельного DHT22 обычно нужна подтяжка DATA 4,7–10 кОм; на готовом модуле она часто уже есть.

## Задание
Каждые 2 с:
1. считать температуру;
2. считать влажность;
3. проверить `isnan()`;
4. вывести:
```text
T:23.5C
H:45.2%
```
При ошибке:
```text
DHT22 ERROR
Check sensor!
```

## Уточнение
Не очищайте LCD перед каждым обновлением; лучше перезаписывать поля фиксированной ширины.
