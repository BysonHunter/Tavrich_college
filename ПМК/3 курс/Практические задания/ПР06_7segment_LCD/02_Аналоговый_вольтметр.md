# Аналоговый вольтметр

[← К общему содержанию](../README.md)

**Плата:** Arduino Uno.  
**Обязательные устройства:** 4-разрядный 7-сегментный индикатор и LCD1602 I²C.

### Исправленная базовая распиновка
В исходнике используются пересекающиеся пины для индикатора, кнопок и датчиков. Для заданий ниже принята единая схема без конфликтов:

| Назначение | Пины |
|---|---|
| сегменты A,B,C,D,E,F,G,DP | D2,D3,D4,D5,D6,D7,D8,D9 |
| разряды DIG1…DIG4 | D10,D11,D12,D13 |
| LCD I²C | A4 SDA, A5 SCL |
| дополнительные устройства | A0…A3 |
| Serial | D0/D1 свободны |

### Электрическое уточнение
Каждый сегмент должен иметь свой резистор. Общие выводы разрядов не следует напрямую нагружать суммой токов всех сегментов; для общего катода рекомендуется управлять DIG1…DIG4 через NPN/NMOS ключи.

### Частота динамической индикации
Переключайте один разряд примерно каждые 1–2 мс. Тогда каждый из четырёх разрядов обновляется с частотой порядка 125–250 Гц.

### Важно
Коды сегментов зависят от типа общего анода/катода и фактического порядка A…G. Проверяйте распиновку, а не копируйте «магические» двоичные значения.

## Цель
Показывать напряжение потенциометра на 7-seg и ADC/процент на LCD.

## Подключение
Потенциометр → A0.

## Задание
1. Считать `adcValue`.
2. Рассчитать:
```text
voltage = adcValue * VREF / 1023.0
```
3. Показать, например, `2.5` с использованием DP.
4. LCD:
```text
ADC: 0512
Level: 50%
```

## Уточнение
`5.0 В` — номинал. Для большей точности измерьте реальное VREF/питание мультиметром и используйте это значение.
