# Управление скоростью потенциометром

[← К общему содержанию](../README.md)

**Оборудование:** Arduino Uno, 28BYJ-48, ULN2003, внешний источник 5 В (рекомендуется).  
**Библиотеки:** `Stepper`, `AccelStepper`.

### Общие технические уточнения
- Для 28BYJ-48 в учебных расчётах часто используют приблизительно **2048 шагов/оборот для полного шага** и **4096 шагов/оборот для полушага**. Реальное значение выходного вала может немного отличаться из-за передаточного отношения редуктора, поэтому точное позиционирование требует калибровки.
- ULN2003 подходит для волнового, полного и полушагового режима. Настоящий токовый микрошаговый режим с ним не реализуется.
- Двигатель лучше питать от отдельного 5 В источника; GND источника и Arduino объединить.
- Для библиотек важен порядок IN1–IN4; распространённый логический порядок для 28BYJ-48 — `IN1, IN3, IN2, IN4`.

## Цель
Изменять скорость потенциометром и направление кнопкой.

## Подключение
- ULN2003 → D8…D11;
- потенциометр → A0;
- кнопка направления → D2↔GND (`INPUT_PULLUP`).

## Задание
1. Считать A0.
2. Преобразовать значение в RPM.
3. Двигатель вращается постоянно.
4. Кнопка меняет направление.
5. Новую скорость выводить только при заметном изменении.

## Исправление диапазона
В исходнике указан диапазон 1–30 RPM. Для 28BYJ-48 это часто нереалистично. Начните с `MAX_RPM = 10…12`, затем экспериментально определите устойчивое значение.
