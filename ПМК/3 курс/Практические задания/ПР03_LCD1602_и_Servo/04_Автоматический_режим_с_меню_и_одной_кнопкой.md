# Автоматический режим с меню и одной кнопкой

[← К общему содержанию](../README.md)

**Оборудование:** Arduino Uno, LCD1602 с I²C-адаптером, SG90.  
**Библиотеки:** `Wire`, `LiquidCrystal_I2C`, `Servo`.

### Общие уточнения
- SG90 управляется сервоимпульсами; библиотека `Servo` формирует их сама. Это не обычный `analogWrite()`.
- Для серво рекомендуется отдельный источник 5 В; GND источника и Arduino объединить.
- Для кнопок удобно использовать `INPUT_PULLUP`. Резисторы 220–510 Ом — не типичные подтягивающие резисторы кнопок.
- LCD1602 имеет только 16 символов в строке.

## Цель
Различать короткое и длительное нажатие и переключать два режима.

## Подключение
Servo D9; кнопка D2↔GND; LCD I²C.

## Исправление логики
Одна кнопка в исходнике должна одновременно переключать Manual/Auto и запускать sweep при удержании. Это неоднозначно.

Примите:
- короткое нажатие <600 мс — переключение MANUAL/AUTO;
- удержание ≥600 мс в MANUAL — sweep 20°↔160° до отпускания.

## MANUAL
```text
Mode: MANUAL
Hold = sweep
```

## AUTO
```text
Mode: AUTO
Pos: 090 deg
```

Автоматическое движение 30°↔150° по треугольному закону.
