# Ручное управление сервоприводом с визуализацией на LCD

[← К общему содержанию](../README.md)

**Оборудование:** Arduino Uno, LCD1602 с I²C-адаптером, SG90.  
**Библиотеки:** `Wire`, `LiquidCrystal_I2C`, `Servo`.

### Общие уточнения
- SG90 управляется сервоимпульсами; библиотека `Servo` формирует их сама. Это не обычный `analogWrite()`.
- Для серво рекомендуется отдельный источник 5 В; GND источника и Arduino объединить.
- Для кнопок удобно использовать `INPUT_PULLUP`. Резисторы 220–510 Ом — не типичные подтягивающие резисторы кнопок.
- LCD1602 имеет только 16 символов в строке.

## Цель
Управлять углом серво потенциометром.

## Подключение
- потенциометр: A0;
- Servo: D9;
- LCD: I²C.

## Алгоритм
```text
adc = analogRead(A0)
angle = map(adc, 0, 1023, 0, 180)
```

## Исправление формата LCD
Строка `Angle: 045 deg ADC: 512` не помещается в 16 символов. Используйте:
```text
Servo: 045 deg
ADC: 0512
```

## Требования
- не выполнять `lcd.clear()` каждый цикл;
- обновлять только изменившиеся поля;
- при необходимости сгладить ADC.
