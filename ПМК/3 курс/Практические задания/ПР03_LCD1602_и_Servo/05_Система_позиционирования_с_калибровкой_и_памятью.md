# Система позиционирования с калибровкой и памятью

[← К общему содержанию](../README.md)

**Оборудование:** Arduino Uno, LCD1602 с I²C-адаптером, SG90.  
**Библиотеки:** `Wire`, `LiquidCrystal_I2C`, `Servo`.

### Общие уточнения
- SG90 управляется сервоимпульсами; библиотека `Servo` формирует их сама. Это не обычный `analogWrite()`.
- Для серво рекомендуется отдельный источник 5 В; GND источника и Arduino объединить.
- Для кнопок удобно использовать `INPUT_PULLUP`. Резисторы 220–510 Ом — не типичные подтягивающие резисторы кнопок.
- LCD1602 имеет только 16 символов в строке.

## Цель
Реализовать ручное управление, калибровку, запись до пяти позиций и воспроизведение.

## Подключение
Servo D9; потенциометр A0; SAVE D2; PLAY D3; LCD I²C.

## События SAVE
- короткое нажатие — сохранить позицию;
- длительное — калибровка.

## Калибровка
1. `Set MIN pos` — выбрать минимум.
2. Следующее длительное удержание — `Set MAX pos`.
3. Проверить `minAngle < maxAngle`.
4. Масштабировать ADC в новый диапазон.

## Память
Массив максимум из 5 углов. Не выходить за границы.

## Воспроизведение
По PLAY плавно пройти все позиции:
```text
Playback 2/5
Pos: 120 deg
```

## Уточнение
Исходник не требует сохранения после выключения. Повышенный уровень — EEPROM.
