# Практическая работа №4
## Составление программ на базе эмулятора КР580ВМ80

### Цель работы

Совершенствовать навыки разработки программ для КР580ВМ80/Intel 8080:

- линейных алгоритмов;
- ветвлений;
- циклов;
- работы с массивами;
- многобайтовой арифметики;
- подпрограмм `CALL/RET`.

---

## Общие требования

Для каждой задачи:

1. составить словесный алгоритм;
2. определить используемые регистры;
3. составить листинг на ассемблере;
4. ввести программу в эмулятор;
5. подготовить минимум два тестовых набора;
6. выполнить программу;
7. проверить результат;
8. приложить скриншоты и таблицу тестирования.

В конце программы должен быть предусмотрен корректный останов `HLT`.

## Задача 1. Сумма двух однобайтовых величин

Исходные данные:

```text
B = U1
C = U2
```

Найти:

```text
U_sum = U1 + U2
```

### Уточнение

Сумма двух байтов может быть больше `255`, поэтому одного регистра `D` недостаточно для полного результата.

В этой версии задания требуется:

```text
D = младший байт суммы
E = 00h, если переноса нет
E = 01h, если CY = 1
```

То есть пара `ED` хранит полный 9-битный результат.

Проверьте минимум два случая:

```text
10 + 20
200 + 100
```

## Задача 2. Минимум из трёх значений

В регистрах:

```text
D = Детали_A
E = Детали_B
H = Детали_C
```

Найти минимальное значение и записать в:

```text
L
```

Используйте `CMP` либо вычитание с анализом `CY/Z`.

Проверьте случаи:

- минимум — первое значение;
- минимум — второе;
- минимум — третье;
- два значения равны.

```text
[2000h] = T1
[2001h] = T2
```

Записать большее значение в:


Если значения равны, можно записать любое из них.

## Задача 4. Максимальная сторона треугольника

Исходные данные:

```text
[2070h] = A
[2071h] = B
[2072h] = C
```

Найти:

```text
max(A,B,C)
```

Результат:

```text
[2075h]
```

В этой задаче проверять существование треугольника не требуется, если преподавателем не указано иное.

## Задача 5. Периметр треугольника

```text
[2050h] = A
[2051h] = B
[2052h] = C
```

Вычислить:

```text
P = A + B + C
```

Максимум:

```text
255 + 255 + 255 = 765 = 02FDh
```

Поэтому результат должен быть двухбайтовым:

```text
[2060h] = младший байт
[2061h] = старший байт
```

Необходимо корректно учитывать `CY`.

## Задача 6. Сумма восьми измерений

Массив:

```text
2100h...2107h
```

Содержит 8 значений температуры `0...50`.

Максимальная сумма:

```text
8 × 50 = 400 = 0190h
```

Следовательно, результат сразу следует считать **двухбайтовым**:

```text
[2108h] = младший байт суммы
[2109h] = старший байт суммы
```

## Задача 7. Максимум массива и его индекс

Массив из 15 элементов:

```text
2300h...230Eh
```

Найти максимальный элемент.

Результаты:

```text
[230Fh] = максимальное значение
[2310h] = индекс максимального элемента, 0...14
```

Если максимум встречается несколько раз, рекомендуется сохранять индекс **первого** найденного максимума.

## Задача 8. Максимальное абсолютное отклонение

Эталон:

```text
[2200h] = R
```

Массив из 10 измерений:

```text
2201h...220Ah
```

Для каждого элемента вычислить:

```text
D = |Xi - R|
```

Найти максимальное `D`.

Результат:

```text
[2210h]
```

### Подсказка

```text
если Xi >= R: D = Xi - R
иначе:       D = R - Xi
```

## Задача 9. Количество элементов выше порога

Массив из 12 байтов:

```text
2400h...240Bh
```

Порог:

```text
[240Ch] = L
```

Подсчитать элементы, для которых:

```text
Xi > L
```

Результат:

```text
[240Dh]
```

Максимальный счётчик равен 12, поэтому одного байта достаточно.

## Задача 10. Работа с подпрограммами

Исходные стороны:

```text
[2500h] = A
[2501h] = B
[2502h] = C
```

Необходимо:

1. найти максимум → `[2510h]`;
2. найти минимум → `[2511h]`;
3. вычислить периметр →:
   - `[2512h]` — младший байт;
   - `[2513h]` — старший байт.

### Требование

Организовать минимум три подпрограммы:

```text
FIND_MAX
FIND_MIN
CALC_PERIMETER
```

Вызовы:

```asm
CALL FIND_MAX
CALL FIND_MIN
CALL CALC_PERIMETER
HLT
```

Каждая подпрограмма должна завершаться:

```asm
RET
```

Если подпрограмма изменяет регистры, которые нужны вызывающему коду, используйте `PUSH/POP` или явно документируйте это.
