# Практическая работа №1
## Адресация информации и вычисление адресов

### Цель работы

Изучить основные способы адресации операндов и научиться вычислять исполнительный адрес при различных способах формирования адреса.

### Задачи

1. Рассмотреть прямую, непосредственную, косвенную, индексную и относительную адресацию.
2. Научиться отличать адресный код команды от исполнительного адреса.
3. Рассчитывать исполнительный адрес для заданных исходных данных.
4. Сравнить способы адресации по сложности и количеству обращений к памяти.

---

## 1. Теоретические сведения

Для выполнения команды процессор должен определить, где находится операнд. **Способ адресации** — правило, по которому из полей команды и состояния процессора определяется местоположение операнда или его исполнительный адрес.

### 1.1. Непосредственная адресация

Операнд находится прямо в коде команды.

```text
КОП | ОПЕРАНД
```

Пример:

```asm
MVI A, 25h
```

Здесь `25h` — не адрес, а само значение.

### 1.2. Регистровая адресация

Операнд находится во внутреннем регистре процессора.

```asm
MOV A, B
```

Регистровая адресация обычно быстрее обращения к оперативной памяти.

### 1.3. Прямая адресация

Адрес операнда задаётся непосредственно в команде:

```text
Aисп = Aк
```

Пример:

```asm
LDA 2050h
```

### 1.4. Косвенная адресация

Команда указывает на регистр или ячейку, содержащую адрес операнда.

```text
команда → указатель → операнд
```

Для КР580ВМ80/Intel 8080 типичный пример — доступ через пару `HL`:

```asm
MOV A, M
```

где `M` означает ячейку памяти по адресу, находящемуся в `HL`.

### 1.5. Индексная адресация

```text
Aисп = Aб + I
```

где:

- `Aб` — базовый адрес;
- `I` — содержимое индексного регистра.

### 1.6. Относительная адресация

```text
Aисп = PC + D
```

где:

- `PC` — счётчик команд;
- `D` — смещение.

> **Важно.** Индексная и PC-относительная адресация в этой работе рассматриваются как общие архитектурные способы адресации. Сам КР580ВМ80/Intel 8080 не имеет полноценных индексных регистров и относительных переходов в том виде, как более поздние процессоры.

## 3. Задание

Пусть номер студента по журналу равен `N`.

Начальное содержимое аккумулятора:

```text
A = N
```

Второй операнд:

```text
X = N + 20
```

Необходимо показать, как выполнить:

```text
A ← A + X
```

каждым способом адресации, указанным в варианте.

### Исправление неоднозначности исходного задания

В исходной методичке одновременно сказано, что первое число находится в аккумуляторе и что оно же хранится в ОЗУ. По образцу решения видно, что в аккумуляторе находится первое число, а **второй операнд** размещается в памяти или в коде команды. Здесь используется именно эта трактовка.

Для каждого способа:

1. укажите, где расположен `X`;
2. покажите условный формат команды;
3. вычислите исполнительный адрес, если он нужен;
4. покажите получение операнда;
5. выполните сложение;
6. укажите результат:

```text
Aрез = N + (N + 20) = 2N + 20
```

Aб = 13

Aисп = 13 + 7 = 20

## 6. Анализ результатов

При сравнении способов адресации учитывайте:

- количество обращений к памяти;
- длину команды;
- возможность работы с массивами;
- гибкость при перемещении данных в памяти;
- необходимость дополнительных регистров;
- скорость получения операнда.

Обычно регистровая и непосредственная адресация требуют меньше дополнительных обращений к памяти, а многоступенчатая косвенная — больше.
