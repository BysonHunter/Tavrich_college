## 1. Вопросы по форме закрытого типа  
### С одним правильным ответом

**1. Что понимается под микроконтроллером?**

1. Набор пассивных электронных компонентов.
2. Микропроцессорная система на одном кристалле, предназначенная для программного управления электронными устройствами.
3. Только модуль питания платы Arduino.
4. Только персональный компьютер с установленной IDE.

**2. Какие основные компоненты обычно входят в состав микроконтроллера?**

1. CPU, память, порты ввода-вывода и периферийные модули.
2. Только монитор, клавиатура и мышь.
3. Только резисторы и светодиоды.
4. Только внешний жесткий диск.

**3. Для чего в микроконтроллере используется Flash-память?**

1. Для временного хранения стека.
2. Для хранения программы и констант.
3. Для измерения аналогового напряжения.
4. Для формирования ШИМ без программы.

**4. Какое назначение имеет EEPROM в микроконтроллере?**

1. Выполнение арифметико-логических операций.
2. Хранение изменяемых данных, которые должны сохраняться после отключения питания.
3. Тактовая синхронизация ядра.
4. Передача данных по UART.

**5. Какая функция Arduino выполняется один раз при запуске программы?**

1. `loop()`
2. `setup()`
3. `digitalWrite()`
4. `analogRead()`

**6. Какая функция Arduino выполняется циклически после `setup()`?**

1. `Serial.begin()`
2. `pinMode()`
3. `loop()`

**7. Какая функция настраивает режим работы цифрового вывода Arduino?**

1. `pinMode()`
2. `Serial.read()`
3. `map()`
4. `millis()`

**8. Какая функция подает высокий или низкий уровень на цифровой пин?**

1. `analogRead()`
2. `digitalWrite()`
3. `Serial.available()`
4. `pulseIn()`

**9. Для чего используется команда `Serial.begin(9600)`?**

1. Для запуска последовательного порта со скоростью 9600 бод.
2. Для включения ШИМ на всех выводах.
3. Для очистки LCD-дисплея.
4. Для программного сброса платы.

**10. Какой интерфейс Arduino использует линии RX и TX?**

1. I2C
2. SPI
3. UART/USART
4. PWM

**11. Какие линии используются в интерфейсе I2C?**

1. MOSI и MISO
2. RX и TX
3. SDA и SCL
4. Trig и Echo

**12. Какие основные линии используются в интерфейсе SPI?**

1. MOSI, MISO, SCK, SS
2. SDA, SCL
3. RX, TX
4. A0, A1

**13. Какая функция считывает значение с аналогового входа Arduino?**

1. `digitalRead()`
2. `analogRead()`
3. `digitalWrite()`
4. `Serial.println()`

**14. Какой диапазон значений обычно возвращает `analogRead()` при 10-битном АЦП Arduino Uno?**

1. 0–1
2. 0–255
3. 0–1023
4. 0–4095

**15. Что такое PWM/ШИМ в задачах программирования микроконтроллеров?**

1. Метод адресации памяти.
2. Импульсный сигнал с изменяемой скважностью для управления средним значением мощности.
3. Протокол обмена только с дисплеем LCD1602.
4. Команда выключения последовательного порта.

**16. Какой модуль предназначен для ультразвукового измерения расстояния?**

1. BMP180
2. DHT22
3. HC-SR04
4. PCF8574

**17. Какие величины измеряет датчик DHT22?**

1. Температуру и влажность.
2. Только атмосферное давление.
3. Только расстояние.
4. Только угол поворота.

**18. Для чего применяется датчик BMP180?**

1. Для измерения атмосферного давления и температуры.
2. Для управления сервоприводом.
3. Для вывода цифр на семисегментный индикатор.
4. Для коммутации мощной нагрузки.

**19. Каким сигналом обычно управляется сервопривод SG90?**

1. Постоянным уровнем HIGH без изменения.
2. ШИМ-импульсами заданной длительности.
3. Только линиями SDA и SCL.
4. Только аналоговым входом A0.

**20. Что означает динамическая индикация многоразрядного семисегментного индикатора?**

1. Одновременное постоянное включение всех сегментов всех разрядов.
2. Поочередное быстрое включение разрядов с подачей соответствующих кодов сегментов.

4. Чтение температуры с датчика.

## 4. Практические задания  
### Профессиональные задачи

### Задание 1. Управление светодиодом через Serial Monitor

Разработайте скетч Arduino, который:

- инициализирует Serial на скорости 9600 бод;
- настраивает встроенный светодиод на пине 13 как выход;
- обрабатывает команды из монитора порта:
  - `1` — включить светодиод;
  - `0` — выключить светодиод;
  - `s` — вывести статус;
- для неизвестной команды выводит сообщение об ошибке.

**Ожидаемый результат выполнения:** программа использует `Serial.begin(9600)`, `pinMode(13, OUTPUT)`, `Serial.available()`, `Serial.read()`, `digitalWrite()`; корректно изменяет состояние светодиода и выводит статус в Serial Monitor.

---

### Задание 2. LCD1602 I2C + сервопривод SG90 + потенциометр

Составьте алгоритм и фрагмент программы для системы **Arduino + LCD1602 I2C + сервопривод SG90 + потенциометр**.

Требования:

- значение с A0 преобразуется в угол 0–180°;
- полученный угол передается сервоприводу;
- на второй строке LCD отображаются текущий угол и исходное значение АЦП.

**Ожидаемый результат выполнения:** использованы библиотеки `Servo.h` и `LiquidCrystal_I2C.h`, функции `analogRead()`, `map()`, `servo.write()`, `lcd.setCursor()`, `lcd.print()`; при изменении положения потенциометра угол сервопривода и показания на LCD обновляются без существенного мерцания.

---

### Задание 3. Управление шаговым двигателем 28BYJ-48

Разработайте программу для шагового двигателя **28BYJ-48** с драйвером **ULN2003**:

1. Выполнить один полный оборот по часовой стрелке со скоростью 5 об/мин.
2. Сделать паузу 2 секунды.
3. Выполнить два полных оборота против часовой стрелки со скоростью 10 об/мин.
4. Выводить на монитор порта направление и число шагов.

**Ожидаемый результат выполнения:** задано `STEPS_PER_REVOLUTION = 2048`; используется библиотека `Stepper`, методы `setSpeed()` и `step()`; для одного оборота выполняется 2048 шагов, для двух оборотов — −4096 шагов.

---

### Задание 4. Система мониторинга на DHT22, BMP180 и HC-SR04

Разработайте структуру программы для Arduino, которая:

- опрашивает DHT22, BMP180 и HC-SR04;
- обрабатывает ошибки чтения;
- циклически выводит данные на LCD1602 I2C:
  - температура/влажность;
  - давление;
  - расстояние;
- переключает страницы с использованием `millis()`.

**Ожидаемый результат выполнения:** программа использует `DHT.h`, `SFE_BMP180.h`, `Wire.h`, `LiquidCrystal_I2C.h`; DHT22 подключен к цифровому пину, BMP180 и LCD — к I2C, HC-SR04 — к Trig/Echo; предусмотрены сообщения `T:ERR H:ERR`, `PRESS ERR` и `No object`.

---

### Задание 5. Счетчик 0–9999 с динамической индикацией

Предложите алгоритм устройства-счетчика от **0 до 9999**, управляемого кнопкой.

Требования:

- значение счетчика отображается на четырехразрядном семисегментном индикаторе методом динамической индикации;
- на LCD1602 I2C выводится строка `Counter: XXXX`;
- предусмотрен антидребезг кнопки.

**Ожидаемый результат выполнения:** реализованы массивы кодов цифр, буфер разрядов, функция `dispTick()`, обработка кнопки с `INPUT_PULLUP` и задержкой/таймером антидребезга; при достижении 9999 следующий счет сбрасывает значение в 0.
