# Вопросы к аккредитации

**Предмет:** «Микропроцессорные системы»

---

## 1. Вопросы по форме закрытого типа
### С одним правильным ответом

**1. Что понимается под микропроцессорной системой?**

1. Любая электрическая цепь с источником питания.
2. Система, основным устройством обработки информации в которой является микропроцессор.
3. Только персональный компьютер с монитором.
4. Набор пассивных электронных компонентов.

**2. Какие устройства являются обязательными для построения типовой МПС?**

1. Микропроцессор, память, устройства/порты ввода-вывода.
2. Только монитор и клавиатура.
3. Только оперативная память и блок питания.
4. Только датчики и исполнительные механизмы.

**3. Какую функцию выполняет постоянное запоминающее устройство в МПС?**

1. Хранит временные результаты вычислений.
2. Хранит программы начального пуска и постоянные данные.
3. Формирует тактовые импульсы.
4. Выполняет арифметические операции.

**4. Какое свойство характерно для оперативной памяти RAM?**

1. Энергонезависимость при отключении питания.
2. Неограниченное хранение программы без питания.
3. Энергозависимость и возможность чтения/записи данных.
4. Стирание только ультрафиолетовым светом.

**5. Какая архитектура использует общую память для команд и данных?**

1. Гарвардская.
2. Фон-неймановская.
3. Конвейерная только с раздельными кэшами.
4. Многопроцессорная кластерная.

**6. Какова разрядность шины данных микропроцессора КР580ВМ80А?**

1. 4 бита.
2. 8 бит.
3. 16 бит.
4. 32 бита.

**7. Какой объём памяти непосредственно адресуется 16-разрядной шиной адреса?**

1. 256 байт.
2. 1 Кбайт.
3. 64 Кбайт.
4. 1 Мбайт.

**8. Какой регистр КР580ВМ80А обычно является источником одного из операндов и приёмником результата арифметико-логических операций?**

1. Счётчик команд PC.
2. Аккумулятор A.
3. Указатель стека SP.
4. Регистр команд IR.

**9. Какой регистр содержит адрес следующей выполняемой команды?**

1. A
2. B
3. PC
4. PSW

**10. Какой флаг устанавливается при нулевом результате операции?**

1. CY
2. P
3. Z
4. S

**11. Что означает непосредственная адресация?**

1. Операнд содержится непосредственно в команде.
2. Адрес операнда хранится только в порте ввода/вывода.
3. Операнд всегда расположен в стеке.
4. Операнд выбирается только по сигналу прерывания.

**12. Какая команда КР580ВМ80А загружает 8-разрядную константу в регистр?**

1. `MOV`
2. `MVI`
3. `JMP`
4. `OUT`

**13. Как команды `MOV` влияют на флаги результата в КР580ВМ80А?**

1. Всегда устанавливают флаг Z.
2. Не модифицируют флаги результата.
3. Всегда сбрасывают флаг CY.
4. Изменяют только флаг S.

**14. Какая команда используется для остановки выполнения программы?**

1. `EI`
2. `HLT`
3. `IN`
4. `CMA`

**15. Что называют машинным циклом микропроцессора?**

1. Полную программу пользователя.
2. Элементарный интервал выполнения, связанный с одним обращением к памяти или устройству ввода-вывода.
3. Один учебный семестр.
4. Только операцию сложения в АЛУ.

**16. Главный недостаток программно-управляемого ввода-вывода заключается в том, что:**

1. Нельзя использовать команды `IN` и `OUT`.
2. Процессор теряет время в цикле ожидания готовности устройства.
3. Невозможно передавать байты данных.
4. ОЗУ становится энергонезависимым.

**17. При вводе-выводе по прерываниям инициатором обмена обычно является:**

1. Внешнее устройство, формирующее запрос прерывания.
2. Только пользователь клавиатуры.
3. Постоянная память.
4. Генератор тактовых импульсов.

**18. Что означает режим ПДП (DMA)?**

1. Программную десятичную поправку аккумулятора.
2. Передачу данных между памятью и устройством без постоянного участия процессора.
3. Полное дублирование программ.
4. Проверку достоверности памяти.

**19. Чем характеризуется изолированный ввод-вывод (I/O mapped)?**

1. Порты ввода-вывода имеют отдельное адресное пространство и доступны командами `IN`/`OUT`.
2. Регистры устройств всегда занимают ячейки ОЗУ.
3. Данные передаются только по стеку.
4. Ввод-вывод возможен только через прерывания.

**20. Какой тип памяти EPROM стирается перед повторным программированием?**

1. Электрическим током побайтно.
2. Ультрафиолетовым излучением.
3. Магнитным полем.
4. Командой `MOV`.

## 2. Вопросы по форме закрытого типа
### Задания на установление соответствия

### 2.1. Соотнесите сигнал микропроцессорной системы и его назначение

| Элемент | Соответствие |
|---|---|
| 1) READY | а) запрос прерывания |
| 2) INT | б) готовность памяти или ВУ к обмену |
| 3) HOLD | в) запрос захвата шин для прямого доступа к памяти |
| 4) WR | г) направление передачи данных от процессора к памяти или ВУ |
| 5) DBIN | д) чтение данных из памяти или ВУ в процессор |

### 2.2. Соотнесите команду КР580ВМ80А и группу команд

| Элемент | Соответствие |
|---|---|
| 1) `MOV` | а) арифметические команды |
| 2) `ADD` | б) команды пересылки данных |
| 3) `JMP` | в) команды передачи управления |
| 4) `IN` | г) команды ввода |
| 5) `PUSH` | д) команды работы со стеком |

### 2.3. Соотнесите способ адресации и его характеристику

| Элемент | Соответствие |
|---|---|
| 1) Непосредственная | а) адрес операнда указан в команде |
| 2) Прямая | б) операнд находится во внутреннем регистре процессора |
| 3) Регистровая | в) операнд расположен в байте/слове команды |
| 4) Косвенно-регистровая | г) адрес операнда формируется как базовый адрес плюс индекс |
| 5) Индексная | д) адрес операнда хранится в регистровой паре |

### 2.4. Соотнесите тип памяти и его особенность

| Элемент | Соответствие |
|---|---|
| 1) SRAM | а) электрически стираемое ПЗУ с многократной перезаписью |
| 2) DRAM | б) статическая быстрая память, обычно используется в кэше |
| 3) ROM | в) динамическая память, требующая регенерации |
| 4) EEPROM | г) энергонезависимая память, программируемая/стираемая блоками |
| 5) Flash | д) постоянная память для хранения неизменяемого кода |

### 2.5. Соотнесите регистр КР580ВМ80А и назначение

| Элемент | Соответствие |
|---|---|
| 1) A | а) счётчик команд |
| 2) PC | б) указатель стека |
| 3) SP | в) аккумулятор |
| 4) HL | г) регистр признаков |
| 5) F | д) регистровая пара, используемая для косвенной адресации памяти |

## 4. Практические задания
### Профессиональные задачи

### Задание 1. Системы счисления, сложение и адресация

Для заданных чисел **3AH** и **27H**:

1. Выполните перевод в двоичную систему счисления.
2. Определите результат сложения.
3. Укажите состояние флагов **Z** и **CY**.
4. Опишите, какой способ адресации целесообразно использовать, если один операнд находится непосредственно в команде, а второй — в ячейке памяти `0010H`.

**Ожидаемый результат выполнения:** представлены корректные переводы, результат `61H`, определены флаги, объяснены непосредственная и прямая/косвенная адресация.

---

### Задание 2. Сложение двух байтов из памяти

Составьте фрагмент программы для **КР580ВМ80А**, который:

- считывает байты из ячеек `0010H` и `0011H`;
- складывает их;
- записывает результат в ячейку `0012H`;
- содержит указание используемых регистров и команд.

**Ожидаемый результат выполнения:** программа использует загрузку адреса/данных, сложение в аккумуляторе, запись результата; приведены мнемокоды и комментарии.

---

### Задание 3. Анализ фрагмента программы

Дан фрагмент программы:

```asm
MVI A, 4EH
MVI B, 22H
ADD B
MOV D, A
HLT
```

Определите:

- конечное содержимое регистров **A**, **B**, **D**;
- состояние флагов **Z** и **CY**;
- порядок проверки результата в эмуляторе.

**Ожидаемый результат выполнения:** `A = 70H`, `B = 22H`, `D = 70H`, `Z = 0`, `CY = 0`; указан режим пошагового выполнения и фиксация регистров.

---

### Задание 4. Программно-управляемый вывод в порт

Разработайте алгоритм программно-управляемого вывода байта `55H` в порт `04H` с проверкой готовности устройства.

Укажите:

- какие действия выполняет процессор при сброшенном флаге READY/BUSY;
- какие действия выполняет процессор при установленном флаге READY/BUSY;
- в какой момент выполняется команда `OUT 04H`.

**Ожидаемый результат выполнения:** описан цикл опроса готовности, команда вывода `OUT 04H` после готовности, указаны недостатки ожидания и условия завершения обмена.

---

### Задание 5. Проектирование состава микропроцессорной системы

Для системы управления светодиодным индикатором и датчиком состояния предложите состав МПС:

- процессор/микроконтроллер;
- ПЗУ;
- ОЗУ;
- порт ввода;
- порт вывода;
- системные шины;
- источник тактирования.

Дополнительно:

1. Определите минимальные требования к памяти.
2. Составьте план тестирования системы.

**Ожидаемый результат выполнения:** предложена структурная схема словами, назначены блоки памяти и портов, описаны тесты ввода, обработки, вывода и реакции на ошибочные состояния.

## 5. Пример экзаменационного задания

Экзаменационное задание может включать:

- **10** тестовых вопросов с одним правильным ответом;
- **2** задания на соответствие;
- **3** открытых вопроса;
- **1** практическую профессиональную задачу.

**Время выполнения:** 60 минут.

### Пример билета

| № | Содержание задания |
|---:|---|
| 1 | Тестовые вопросы: № 1, 5, 7, 8, 10, 12, 14, 16, 18, 20 из банка заданий. |
| 2 | Задания на соответствие: № 2 и № 4 из банка заданий. |
| 3 | Открытые вопросы: 1) Что хранит PC? 2) Назовите команды обращения к портам ввода-вывода. 3) Что означает режим ПДП? |
| 4 | Практическая задача: составить программу сложения двух байтов из памяти и записи результата по заданному адресу. |
