# Tavrich College — учебно-методические материалы

Репозиторий содержит учебно-методические материалы Таврического колледжа для студентов специальности **09.02.01 «Компьютерные системы и комплексы»**.

Основные направления репозитория:

- **МДК.02.01 «Микропроцессорные системы»**;
- **МДК.02.02 «Программирование микроконтроллеров»**;
- рабочие программы для 3 и 4 курса;
- фонды оценочных средств для 3 и 4 курса;
- материалы для подготовки к аккредитации.

Документы представлены преимущественно в формате **Markdown (`.md`)**. В рабочих программах и фондах оценочных средств используется также HTML-разметка внутри Markdown для сохранения сложных таблиц, объединённых ячеек и отдельных элементов исходного форматирования.

# 4. Взаимосвязь документов

| Документ | Назначение |
|---|---|
| **Рабочая программа (РП)** | Определяет цели, компетенции, результаты обучения, объём и содержание дисциплины. |

Рабочая программа отвечает на вопрос **«что изучается»**, ФОС — **«что и как оценивается»**, а банк аккредитационных заданий — **«на каких конкретных заданиях можно подготовиться и проверить знания»**.
