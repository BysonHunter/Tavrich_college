# Учебно-методические материалы

Репозиторий содержит учебно-методические материалы Таврического колледжа для студентов специальности **09.02.01 «Компьютерные системы и комплексы»**.

Основные направления репозитория:

- **МДК.02.01 «Микропроцессорные системы»**;
- **МДК.02.02 «Программирование микроконтроллеров»**;
- рабочие программы для 3 и 4 курса;
- фонды оценочных средств для 3 и 4 курса;
- материалы для подготовки к аккредитации.

Документы представлены преимущественно в формате **Markdown (`.md`)**. В рабочих программах и фондах оценочных средств используется также HTML-разметка внутри Markdown для сохранения сложных таблиц, объединённых ячеек и отдельных элементов исходного форматирования.

# 2. МДК.02.02 «Программирование микроконтроллеров»

## 2.1. Рабочая программа

[`РП_МДК0202_Программирование_микроконтроллеров_КСК_2025.md`](./РП_МДК0202_Программирование_микроконтроллеров_КСК_2025.md)

Рабочая программа посвящена базовой подготовке по программированию микроконтроллерных систем.

Основные темы:

- архитектура микроконтроллеров AVR;

- среда разработки и язык C;
- Arduino;
- цифровые входы и выходы;
- прерывания;
- таймеры-счётчики;
- UART/USART;
- I2C/TWI;
- SPI;
- подключение периферийных устройств;
- АЦП;
- аналоговые датчики;
- управление нагрузкой и двигателями;
- энергосбережение;
- структурное программирование;
- итоговый проект системы автоматического контроля.

Практическая часть включает разработку первых программ для микроконтроллеров, работу с входами и выходами, прерываниями, таймерами, UART, I2C, аналоговыми датчиками и прикладным проектом.
