# Tavrich College — учебно-методические материалы

Репозиторий содержит учебно-методические материалы Таврического колледжа для специальности **09.02.01 «Компьютерные системы и комплексы»**.

- **МДК.02.01 «Микропроцессорные системы» (МПС)**;
- **МДК.02.02 «Программирование микроконтроллеров» (ПМК)**;
- материалы для **3 и 4 курса**;
- рабочие программы;
- фонды оценочных средств;
- входной контроль;
- вопросы к аккредитации;

> Официальные учебно-методические документы находятся в корне репозитория, а непосредственные учебные материалы по курсам — в папках `МПС` и `ПМК`.

# 5. Как связаны материалы

| Тип материала | Назначение |
|---|---|
| **Рабочая программа** | Определяет цели, компетенции, результаты, объём и содержание обучения. |

| **Лекции** | Содержат основной теоретический материал. |

# 7. Формат материалов

Основной формат документов — **Markdown (`.md`)**. Для просмотра подходят GitHub, Visual Studio Code, Obsidian, Typora, MarkText и другие Markdown-редакторы.

Часть рабочих программ и ФОС содержит HTML-разметку внутри Markdown для сохранения сложных таблиц и элементов исходного форматирования. Графические материалы хранятся преимущественно в `.png` и `.jpg`.
