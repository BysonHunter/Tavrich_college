# Tavrich College — учебно-методические материалы

Репозиторий содержит учебно-методические материалы Таврического колледжа для специальности **09.02.01 «Компьютерные системы и комплексы»**.

Основные учебные направления:

- **МДК.02.01 «Микропроцессорные системы» (МПС)**;
- **МДК.02.02 «Программирование микроконтроллеров» (ПМК)**.

В репозитории собраны рабочие программы, фонды оценочных средств, материалы для аккредитационного мониторинга, входной контроль и лекции для 3 и 4 курса.

> Для удобства навигации служебные каталоги `images` и отдельные графические файлы в этом README не перечисляются.

# 7. Как пользоваться репозиторием

### Для изучения дисциплины

1. Откройте соответствующую рабочую программу в [`РПД`](./РПД/).
2. Перейдите в папку дисциплины:
   - [`МПС`](./МПС/) — микропроцессорные системы;
   - [`ПМК`](./ПМК/) — программирование микроконтроллеров.
3. Выберите курс — **3 курс** или **4 курс**.
4. Откройте нужную лекцию.
5. Для проверки знаний используйте [`ФОС`](./ФОС/) и материалы [`АккМон`](./АккМон/).

### Для подготовки к контролю и аккредитации

- входной контроль — [`ФОС`](./ФОС/);
- фонды оценочных средств — [`АккМон`](./АккМон/);
- вопросы к аккредитации — [`АккМон`](./АккМон/).
